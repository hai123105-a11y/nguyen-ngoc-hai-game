Cách Chơi & Vật Phẩm Hỗ Trợ

Nắm vững các phím điều khiển và thuộc tính của vật phẩm để đạt điểm số kỷ lục!

Điều Khiển Trên Máy Tính

  • WASD hoặc ↑←↓→ : Di chuyển chiến hạm
  • Space hoặc Chuột Trái : Bắn đạn laser liên thanh
  • B hoặc Enter : Kích nổ bom EMP quét sạch màn hình
  • P hoặc Esc : Tạm dừng trò chơi

Điều Khiển Trên Điện Thoại

  • Chạm & Kéo ngón tay : Tàu di chuyển mượt mà bám theo vị trí ngón tay
  • Tự động bắn : Chiến hạm tự khai hỏa khi ngón tay đang chạm màn hình
  • Nút EMP Bomb : Chạm nút bom trên thanh điều khiển để dọn quái vật
  • Nút Fullscreen : Bật chế độ tràn màn hình để chơi game trọn vẹn

Các Vật Phẩm Rơi Ra Khi Tiêu Diệt Kẻ Địch

⚡

Triple Shot

Bắn ra 3 tia đạn chùm mở rộng góc bắn, tiêu diệt hàng loạt quái vật.

🛡️

Energy Shield

Tạo một lớp khiên bảo vệ hấp thụ hoàn toàn 1 lần va chạm với kẻ địch.

💣

EMP Bomb

Thêm 1 lượt kích nổ bom xung điện, xóa sổ tức thì mọi mục tiêu trên màn hình.

⏳

Time Slow

Làm chậm tốc độ bay của toàn bộ quái vật và đạn địch trong vòng 5 giây.

Ngôn Ngữ & Kỹ Thuật Đồ Họa

Trò chơi được xây dựng hoàn toàn từ các ngôn ngữ và thư viện web thuần túy, không sử dụng framework cồng kềnh:

01

HTML5 Canvas 2D Engine

Kết xuất đồ họa 60 FPS mượt mà thông qua vòng lặp requestAnimationFrame. Tính toán tọa độ vector, gia tốc vật lý và va chạm hitbox chính xác.

Canvas Context 2D Vector Math Collision Hitbox
02

JavaScript (ES6+) Object Engine

Xây dựng theo mô hình hướng đối tượng (OOP) quản lý các thực thể Player, Enemies, Bullets, Particles và Power-ups độc lập.

OOP Architecture Particle System State Management
03

Web Audio API Synthesizer

Tự động tổng hợp sóng âm (Oscillator, GainNode, White Noise) tạo hiệu ứng âm thanh 8-bit sống động mà không cần tải bất kỳ file MP3/WAV bên ngoài nào.

Zero Audio Files Custom Synthesizer Spatial Audio
04

Python 3 Local Auto Server

File run.py đi kèm sử dụng thư viện chuẩn của Python để khởi chạy web server nội bộ và tự động kích hoạt trình duyệt chỉ với 1 click.

Built-in http.server Auto Webbrowser Zero Dependencies
Khởi chạy 1-Click

Chạy Full Web Game Local Bằng Python

Chỉ cần gõ 1 lệnh hoặc nhấp đúp file run.py, máy chủ nội bộ sẽ tự kích hoạt tại http://localhost:8000 và tự động mở trình duyệt web lên để bạn chơi game ngay lập tức!

1
Mở thư mục dự án: Truy cập vào thư mục nguyen-ngoc-hai-game
2
Gõ lệnh chạy:
python3 run.py
3
Trải nghiệm: Game sẽ tự động bật lên trên màn hình và sẵn sàng chiến đấu!
Xem file run.py Lên chơi game ngay
Terminal - run.py
$ python3 run.py
